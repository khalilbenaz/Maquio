De la maquette au code natif.

Maquio est un éditeur d'interfaces mobiles pour macOS, Windows et Linux. Dessinez avec de vrais composants, jouez le prototype, puis exportez du code compilé pour Flutter, React Native, SwiftUI et Jetpack Compose.

Télécharger Maquio Voir le dépôt

Gratuit et libre (licence MIT). Version 1.0.

    Tout ce qu'il faut, de l'idée au code

    Un seul document .maquio, du JSON lisible qui vit dans votre dépôt à côté du code qu'il décrit.

    Des composants mobiles natifs

    Boutons, champs, interrupteurs, listes, barres d'application et de navigation, tiroirs, dialogues, feuilles basses : 30 composants et 7 conteneurs, avec recherche et glisser-déposer. Chacun est exporté vers le widget natif de la cible, pas vers un rectangle avec du texte.

    Interactions, transitions et mode prototype

    Chaque élément peut naviguer, revenir en arrière, ouvrir un dialogue, une feuille basse ou un snackbar, avec une transition (glissement, poussée, fondu, modale). Les liens se tracent en flèches sur le canevas, puis ▶ Prototype joue le parcours en plein écran.

    Un export compilé vers quatre cibles

    Tous les écrans sont exportés avec leur navigation, leur thème et leurs composants. Le code généré est vérifié pour de vrai : flutter analyze, swiftc, tsc --strict et Gradle.

    Assistance Claude

    Décrivez un changement en français : Claude Code répond par un patch validé par schéma, appliqué comme un geste de souris, donc annulable en un seul Ctrl+Z. Maquio lance le binaire claude déjà installé, sans clé d'API.

    Import et export Figma

    Importez une maquette depuis l'API Figma ou un fichier JSON : ce qui n'a pas d'équivalent devient un espace réservé signalé, jamais perdu en silence. Dans l'autre sens, le plugin « Import Maquio » recrée frames, composants et réactions de prototype dans Figma.

    Thème clair ou sombre, panneaux repliables

    L'éditeur suit votre système ou le thème de votre choix. Calques, inspecteur et panneau Claude se replient d'un raccourci (Ctrl+Alt+1, Ctrl+Alt+2, Ctrl+J) et le mode focus ne laisse que le canevas.

    Galerie : maquette et rendu

    Le prototype bancaire fictif « nacre » (16 écrans) reproduit d'après une maquette de référence. Pour chaque écran, la maquette est à gauche et le rendu de Maquio à droite.

    Installation

    Téléchargez le paquet de votre système depuis les releases. Les versions ne sont pas encore signées : voici comment les ouvrir.

    macOS

    Fichier .dmg ou .zip universel (Apple Silicon et Intel).

    1. Ouvrez le .dmg et glissez Maquio dans Applications.
    2. Au premier lancement, Gatekeeper refuse l'app non signée : faites un clic droit → Ouvrir, puis confirmez Ouvrir.
    3. Si le message persiste : Réglages Système → Confidentialité et sécurité → « Ouvrir quand même ».

    Windows

    Installeur .exe (x64 ou arm64).

    1. Lancez l'installeur.
    2. SmartScreen peut afficher « Windows a protégé votre ordinateur » : cliquez sur Informations complémentaires, puis Exécuter quand même.
    3. Suivez l'assistant d'installation.

    Linux

    Fichier .AppImage ou paquet .deb (x64).

    chmod +x Maquio-*.AppImage
./Maquio-*.AppImage

    Pour le .deb : sudo apt install ./Maquio-*.deb.

    Les sommes de contrôle SHA-256 sont publiées avec chaque release (SHA256SUMS.txt). Pour l'assistance Claude, installez le CLI claude : Maquio le détecte automatiquement.
